
# Sistema de Eleição

Sistema de console desenvolvido em C# com .NET para simular uma eleição.

## Funcionalidades

- Cadastro de candidatos.
- Registro de eleitores.
- Prevenção de votos duplicados.
- Contabilização de votos válidos, nulos e brancos.
- Apuração dos resultados.

## Como executar

```bash
dotnet run --project SistemaEleicao.Console/SistemaEleicao.Console.csproj
```

## Como executar os testes

```bash
dotnet test
```

## Tecnologias

- C#
- .NET
- xUnit
- Git
